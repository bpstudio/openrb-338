Hi!

This VST3 version is under heavy development, use it your own risk!

- synced with transport bar play/stop but not the position
- saves the last loaded song as plugin/preset data, so restored at load with the project (hopefully)
- no midi output yet
- partial midi support (no sample precision)
  channel 1-4 and 10-11 (replica of midi channel 3-4)
  sometimes note offs ignored
- partial vst parameter automation

- the tempo is not set from the .rbs file automatically, 
  use cmd-I to check the original tempo and setup your DAW's tempo.
